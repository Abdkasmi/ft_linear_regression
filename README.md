# ft_linear_regression

This project is a simple implementation of **linear regression** with one variable in Python, using the **gradient descent** algorithm.

The goal is to predict the **price of a car** based on its **mileage** (`km`).

---

## 📁 Project Structure

- `data.csv`: Training dataset (km, price).
- `ft_linear_regression.py`: Script to train the model and compute the parameters `theta0` and `theta1`.
- `theta.csv`: Generated file containing the learned model parameters.
- `predict.py`: Allows predicting the price of a vehicle based on its mileage.

---

## 🧠 Concepts Used

- **Linear Regression**
- **Gradient Descent**
- **Data Normalization**

---

## ⚙️ Training the Model

```bash
python ft_linear_regression.py
```
## ⚙️ Prediction

```bash
python predict.py
```
